## 결과

- 워크북 31개 시트, 비어 있지 않은 1,244,784셀: 재생성본과 차이 0건.
  이 중 숫자 셀 789,816개는 직렬화 오차 허용치 rel/abs 2×10⁻¹⁵로 비교했고,
  텍스트·수식·불리언은 정확히 비교했다. 이는 물리 계산 정확도 기준이 아니다.
- 현재 Word 본문 그림 5개와 SI 그림 7개의 삽입 PNG는 저장소의
  `figures/*.png`와 SHA-256이 전부 일치.
- 받은 원본 Word와 비교해 표 내용은 동일. 본문 텍스트 변경은 Fig. 3(a)의
  orange/blue → dark gray/light gray 한 곳뿐이며 의도된 캡션 수정이다.

## 방법

저장소의 문서 생성 코드·결과 파일을 임시 작업 폴더로 복사하거나 읽기 전용
입력으로 연결하고 `make_workbook.py` 및 `si_build.py`를 실행했다.
SI 생성기는 본문 원고도 함께 생성한다. 재생성된 표 전체, 워크북 전체 시트 및
본문 문단을 현재 문서와 대조했다. 연구 코드와 원고·SI 원본은 수정하지 않았다.
워크북 집계는 표시된 표 셀 수가 아니라 저장된 모든 비어 있지 않은 셀의 수다.

## 검증 제외와 제한

- 현재 환경에 PySCF가 없어서 `facts.compute()` 안의 H₄ 삼중항 갭 독립 계산은
  임시 사본에서만 NaN으로 대체했다. 이 값은 워크북과 표에는 사용되지 않는다.
  본문과 SI의 3.4 mHa 주장은 이번에 확인한 값으로 취급하면 안 된다.
- 재생성 문단의 차이는 위 갭을 포함한 문단 두 곳과, 예전 캡션을 내보내는
  원본 문서 생성기 때문에 생기는 Fig. 3(a) 캡션 한 곳이다. 나머지 문단은 일치.
- 이 검사는 저장된 JSON → 워크북·표·본문 연결의 일관성 검사다.
  같은 생성 코드를 사용했으므로 원래 코드에 공통으로 존재할 수 있는 오류,
  알고리즘·물리 모델·이론적 주장 자체의 정확성을 독립적으로 입증하지 않는다.
- 전자구조 에너지·기울기·최적화의 새 계산은 수행하지 않았다.
- 그림 이미지 바이트 일치는 확인했지만 새로 전체 패널을 시각적으로 재검토하거나
  저장된 그림의 모든 점을 독립적으로 역추출하지는 않았다.
- 저자·소속·교신 이메일·감사·기여도·이해상충과 공개 URL·DOI 빈칸은 그대로 남아 있다.

## 판단

현재 검사 범위에서 원고·SI와 업로드 자료 사이의 수치 불일치는 발견하지 못했다.
전체 과학 계산 검증 완료 또는 투고 준비 완료를 뜻하지는 않는다.

기계 판독 결과와 입력 파일 해시는 `PAPER_DATA_AUDIT.json` 파일에 기록했다.

저자 정보·기여도·코드 및 데이터 제공 문구는 이 대조 이후 원고에 반영됐다.
연구 표와 그림은 해당 수정에서 보존 여부를 확인했다. 상세 결과는
`PAPER_DATA_AUDIT.json`에 보관한다.
